# PANN: 電力変換器のための物理情報埋め込み型ニューラルネットワーク

## プロジェクト概要
本プロジェクトは、電力変換器のモデリングのための革新的なアプローチである**PANN (Physics-in-Architecture Neural Network)** の実装を含む先行研究のソースコードです。物理法則を直接ニューラルネットワークのアーキテクチャに組み込むことで、高精度かつデータ効率の良いモデリングを実現しています。

## 参考論文
### 主要論文
1. **PANNの基礎**: "Temporal Modeling for Power Converters With Physics-in-Architecture Recurrent Neural Network" (IEEE TIE, 2024)
   - 物理法則に基づく再帰型ニューラルネットワーク
   - 離散化された状態空間方程式の直接埋め込み

2. **PE-GPT**: "PE-GPT: A New Paradigm for Power Electronics Design" (2025)
   - 電力エレクトロニクス設計のための新しいAIパラダイム
   - 大規模言語モデルを活用した設計最適化

## PANNの特徴

### 1. 物理法則の直接埋め込み
- 回路の状態空間方程式を離散化してネットワーク構造に組み込み
- 物理的一貫性を保証しながら高精度な予測を実現

### 2. データ効率性
- 従来手法と比較して3桁少ないデータ量で学習可能
- 理論的には、定義された変換器パラメータ数と同程度のデータポイントで十分

### 3. 軽量性
- 単層の再帰型ニューラルネットワークに類似した構造
- パラメータ数が少なく、計算効率が高い

### 4. 柔軟性
- 動作条件の変更に対応
- 変調戦略の最適化
- 性能指標のカスタマイズ
- トポロジーバリエーションへの転移学習

### 5. 説明可能性
- 回路の物理原理を明確に反映
- スイッチング動作や転流ループを可視化可能

## PANNの動作原理

### 1. アーキテクチャ
- 入力層：制御信号（ゲート信号、デューティ比など）
- 隠れ層：離散化されたPDEを表現する再帰構造
- 出力層：状態変数（電流、電圧）

### 2. 学習プロセス
- 少数のサンプルデータから物理パラメータを学習
- 物理法則に基づく帰納バイアスにより高速収束
- 1エポックの学習で十分な精度を達成可能

### 3. 推論フロー
1. 前時刻の状態変数を入力
2. 離散化された物理方程式により次状態を計算
3. 再帰的に時系列全体を予測
4. リアルタイム制御に適用可能

## 応用分野
- **設計最適化**: 物理法則に基づく高速な性能評価
- **制御**: リアルタイム状態推定と予測制御
- **故障診断**: パラメータ変動の検出と同定
- **教育**: 電力変換器の動作原理の可視化
